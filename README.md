# dsh-study

给 DeepSeek Harness 用的「自主学习」面板。

后台跑着一个学习脚本（每半小时看一次 B 站字幕或本地文本，写完笔记进记忆库），
这个插件把它的开关搬到前台来，不用再改 JSON、动计划任务。

## 两处界面

- **右下角小鲸鱼**：点开能看到今天的轮次和最近读过的几篇，气泡里两个按钮。
- **设置 → 插件 → 自主学习**：同样的开关，写得更细。

两个按钮的意思：

1. **开 / 停** —— 立刻改总开关。关着的状态下脚本到点也不会跑。
2. **跑完这一轮再停** —— 挂个收摊标记，当前这一轮跑完就自动关掉总开关。

角标上的数字是今天学了几轮；鲸鱼变暗＝停着，不烧额度。

## 依赖的后端

插件只做壳，读写都走本机路由 `/api/study`（只允许 127.0.0.1）：

- `GET  /api/study` → 开关、今日轮次、最近笔记、上次为什么停
- `POST /api/study` → `{ action: "toggle" | "stopAfter" | "enable" | "disable" }`

真正的状态落在 `control.json`，所以面板挂了、DSH 没开，学习脚本照样认这个开关。
